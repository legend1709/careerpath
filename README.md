# CareerPath - Career Recommendation System

## Project Description

CareerPath is a comprehensive web-based career guidance and recommendation platform designed for students to discover their ideal career paths. The application uses a rule-based recommendation engine to match students' interests, skills, and preferences with suitable careers.

## Features

### Student Features
- User registration and secure authentication
- Multi-section career assessment questionnaire
- Personalized career recommendations based on assessment results
- Compatibility scoring and ranking system
- Detailed career information and job role descriptions
- Assessment history and results tracking
- Career exploration and browsing
- Responsive dashboard with statistics

### Admin Features
- Admin dashboard with system statistics
- User management and viewing
- Career management (Add, Edit, Delete)
- Assessment submission monitoring
- Recommendation tracking
- Complete CRUD operations for careers

### Core Features
- **Modern UI**: Professional design with gradient theme, smooth animations, and responsive layout
- **Authentication**: Secure password hashing and session management
- **Database**: SQLite with automatic initialization
- **Recommendation Engine**: Rule-based matching system with keyword scoring
- **Error Handling**: Custom error pages (404, 500)
- **Mobile Responsive**: Works seamlessly on desktop, tablet, and mobile devices

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python Flask
- **Database**: SQLite3
- **Security**: Werkzeug (password hashing)
- **Templating**: Jinja2
- **Icons**: Font Awesome CDN
